🌟 What is MindustryArk?

MindustryArk is a self-built launcher that lets you enjoy the popular game Mindustry on devices running HarmonyOS NEXT or OpenHarmony. It also works perfectly on Windows, so you can play wherever you are.

Think of it as a magic key that opens the door to Mindustry on platforms where it wasn't originally available. No complicated coding or technical knowledge needed – just download, run, and play!

💻 What You'll Need

For Windows

  • ✅ Windows 10 or 11 (64-bit)
  • ✅ 4GB RAM (8GB recommended)
  • ✅ 500MB free disk space
  • ✅ A graphics card that supports OpenGL 3.2+

For HarmonyOS / OpenHarmony

  • ✅ HarmonyOS NEXT or OpenHarmony 4.0+
  • ✅ 4GB RAM or more
  • ✅ 500MB free storage space
  • ✅ Supports ARM64 architecture

🛠️ Troubleshooting Tips

⚠️ If the app doesn't start:

Make sure your device meets the minimum requirements listed above. Also, check that you have the latest version of the launcher from the download page.

✅ If you see a "permission" prompt:

It's normal! The app needs permission to access your device's storage and graphics resources to run the game. Click "Allow" to proceed.

Still having trouble? The community is here to help! Check the GitHub repository for discussions, or open an issue if you've found a bug.
